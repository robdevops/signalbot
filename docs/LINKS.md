# Links

A message that addresses the bot and has a URL, or replies to a message with one, gets the page read for the model: up to 2 links, the page's main text up to 15,000 characters, a PDF link as a PDF (see [Files](FILES.md)). Only links a person sent are fetched, never ones the model or a page suggests, so a link in a reply to one of the bot's own messages isn't fetched. A link to a private or local address (the bot's own machine, your network, a cloud metadata service) is refused, however its name resolves, and the model is told it couldn't load it. So is a link that looks private or one-time, so asking "is this legit?" can't spend it: a reset, confirmation, unsubscribe or webhook link, or one carrying a token, key or signature, including where a short link redirects. Each chat can have 20 links fetched an hour. The log records each link's size and how much text was read, never the link itself.
